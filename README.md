# Netflix Data Analysis

## Overview

Exploratory Data Analysis (EDA) of Netflix Movies & TV Shows dataset to identify trends, content distribution, and business insights.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Key Insights

* Majority of content available is **Movies**.
* Significant growth in content after **2015**.
* **United States** produces the highest number of titles.
* **TV-MA** is one of the most common ratings.
